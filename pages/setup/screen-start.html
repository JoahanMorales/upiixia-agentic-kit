      Words you will see
      claim
      An agent takes a task so nobody else works on it at the same time.
      freeze
      The time before the deadline when new work stops, so the last minutes go to the demo.
      lint
      An automatic check of the plan: it finds tasks that are incomplete or depend on each other in a loop.
      wave
      A group of tasks that can be done at the same time; wave 2 starts when wave 1 is done.
      worktree
      A separate folder for one task, so two agents never edit the same files at once.
      PR
      A pull request: the proposed change of one task, which another agent reviews before it joins main.
      origin
      The name Git gives your project's copy on GitHub.
      MCP
      The way a coding tool talks to the kit's own commands; the tool asks you to approve it once.
